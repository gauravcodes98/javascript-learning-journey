## 📚 Topics Covered

### 1. JavaScript Data Types

JavaScript data types are divided into two main categories:

**Primitive Data Types:**
- String
- Number
- BigInt
- Boolean
- Undefined
- Null
- Symbol

**Non-Primitive Data Types:**
- Object
- Array
- Function

### 2. The `typeof` Operator

The `typeof` operator is used to determine the data type of a variable at runtime.

### 💻 Code Examples

```javascript
// String
let name = "Gaurav";
console.log(typeof name); // string

// Number
let age = 22;
console.log(typeof age); // number

// Boolean
let isStudent = true;
console.log(typeof isStudent); // boolean

// Undefined
let city;
console.log(typeof city); // undefined

// Null
let value = null;
console.log(typeof value); // object

// Object
let student = {
    name: "Gaurav",
    age: 22
};
console.log(typeof student); // object

// Array
let skills = ["HTML", "CSS", "JavaScript"];
console.log(typeof skills); // object
```

## 🔑 Key Learnings

- JavaScript is a dynamically typed programming language.
- Variables can store different types of values.
- `typeof` helps identify the data type.
- `typeof null` returns `"object"` due to a historical JavaScript behavior.
- Arrays are also considered objects in JavaScript.
