# 🚀 Day 01 – Introduction to JavaScript

📅 **Date:** 01 November 2026

Today I started my JavaScript learning journey. I explored the history of JavaScript, its inventor, how it was developed, and how JavaScript code executes.

## 📚 1. What is JavaScript?

JavaScript is a high-level programming language used to make websites interactive and dynamic.

**Uses of JavaScript:**
- Frontend Development
- Backend Development
- Web Applications
- Mobile Applications
- Server-side Development

## 👨‍💻 2. Who Invented JavaScript?

- **Creator:** Brendan Eich
- **Year:** 1995
- **Company:** Netscape Communications
- **Original Name:** Mocha
- **Second Name:** LiveScript
- **Final Name:** JavaScript

Brendan Eich developed JavaScript in May 1995 while working at Netscape. Its initial implementation was created in approximately 10 days.

## 📖 3. History of JavaScript

| Year | Event |
|---|---|
| 1995 | JavaScript was created |
| 1995 | Initially named Mocha |
| 1995 | Renamed LiveScript |
| 1995 | Renamed JavaScript |
| 1996 | Microsoft introduced JScript |
| 1997 | JavaScript standardized as ECMAScript |

## ⚙️ 4. How Was JavaScript Created?

JavaScript was developed to make web pages interactive.

Before JavaScript, HTML was mainly used to structure web pages, and websites had limited interactivity.

Brendan Eich created JavaScript for Netscape Navigator.

## 🧠 5. What is a JavaScript Engine?

A JavaScript Engine is a software program that reads, processes and executes JavaScript code.

**Examples:**
- V8 Engine – Google Chrome and Node.js
- SpiderMonkey – Firefox
- JavaScriptCore – Safari

## 🔥 6. What is V8 Engine?

V8 is an open-source JavaScript Engine developed by Google.

**Important Points:**
- Written primarily in C++.
- Used in Google Chrome.
- Used by Node.js.
- Uses compilation and execution techniques.
- Converts JavaScript into machine instructions.

## 💻 7. How Does a JavaScript Engine Work?

Basic execution process:

1. JavaScript Source Code
2. Parsing
3. Bytecode Generation
4. Execution
5. Optimization and Machine Code

Modern engines use both interpretation and Just-In-Time (JIT) compilation.

## 🟢 8. What is Node.js?

Node.js is a JavaScript runtime environment that allows JavaScript code to execute outside the browser.

**Key Points:**
- Uses the V8 JavaScript Engine.
- Used for backend development.
- Supports server-side applications.
- Allows JavaScript execution through the terminal.

## 🎯 10. Key Takeaways

- JavaScript was created by Brendan Eich in 1995.
- JavaScript was initially named Mocha.
- JavaScript was developed at Netscape.
- JavaScript is different from Java.
- ECMAScript defines the JavaScript language standard.
